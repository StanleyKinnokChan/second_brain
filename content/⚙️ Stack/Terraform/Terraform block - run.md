

- run block defines **one test case**
- sit in a `.tftest.hcl` file as the **core unit of test execution**
- Terraform run block assertions are [Custom Conditions](https://developer.hashicorp.com/terraform/language/expressions/custom-conditions), consisting of a [condition](https://developer.hashicorp.com/terraform/language/expressions/custom-conditions#condition-expressions) and an [error message](https://developer.hashicorp.com/terraform/language/expressions/custom-conditions#error-messages).
