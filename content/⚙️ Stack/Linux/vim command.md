:wq  = save and quit
:q! = abort and quit
:i = insert (add text before cursor)
:a = append  (add text after cursor)

esc = back to normal mode


LHJK = right, left, down, up (combining with number, e.g. 5J = 5 lines up)
$ = move end of current line
0 = move end of current line
w = move forward a word, b = move backward a word
gg = start of the line , G = final line
25G = to line 25
