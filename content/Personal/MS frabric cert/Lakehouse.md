A **lakehouse** presents as a database and is built on top of a data lake using Delta format tables.
- built on top of the **OneLake** scalable storage layer
- uses Apache Spark and SQL compute engines for big data processing. 
- can load data - in any common format - from various sources; including local files, databases, or APIs

A lakehouse is a unified platform that combines:
- The flexible and scalable storage of a data _lake_
- The ability to query and analyze data of a data warehouse_
