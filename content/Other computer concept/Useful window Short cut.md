tags:

window + shift + left/right = switch window between screen
window + x = all system manual; +u+r restart & +u+u shutdown
window + v = clipboard history
window + D = display desktop
window + L = Lock computer
window + E = File explore
window + I = File explore
window + R = run dialog
window + P = change display mode
Window + Shift + S = Regional snapshot
window + . = emoji keyboard

Ctrl + Shift + Esc = task manager
Alt + tab = switch tabs

Ctrl + W =  closes a tab
Ctrl + shift + t = open last closed tab in browser
click * 3 = highlight the whole paragraph
