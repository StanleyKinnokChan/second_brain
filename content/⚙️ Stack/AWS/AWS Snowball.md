# AWS Snowball

- Highly-secure, portable devices to collect and process dataat the edge, and migrate data into and out of AWS (Petabytes of data)
- move large amounts of data IN and OUT of AWS
- physical storage device in suitcase/ truck ordered from AWS (so it is **offline**!)


Snowball overcome these challenge:
- Lmiited connectivity/ bandwidth
- high network cost
- Shared bandwidth
- connection stability

**Snowball**

- **only storage**
- **10TB to 10PB economical range**
- Data encryption uses KMS
- use 1 Gbps/ 10Gbps network

**Snowball Edge**

- **both storage & compute** optmized
- Type
    - storage optimized with EC2
    - compute optimized….with GPU
- data processing on ingestion is needed, can preprocess the data/ encoding...

**Snowmobile**

- special order for a truck (up to 100PB)
- when 10 PB+ is required
